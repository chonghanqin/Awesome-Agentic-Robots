## Project notes and date sources

- **[AW-0: Agentic World Action Models](https://agentic-wam.github.io/)** — Combines code-based reusable skills with joint future-video and action prediction for bimanual manipulation. Date: 2026-10-21 (arXiv v1; [source](https://arxiv.org/abs/2610.30136)).
- **[Plumb](https://yubel426.github.io/Plumb/)** — Uses a coding agent and 3D tools to reconstruct dynamic scenes from video as executable MuJoCo models. Date: 2026-10-21 (Repository creation; paper listed as coming soon; [source](https://api.github.com/repos/Inception3D/Plumb)).
- **[Embodied Playground](https://winniechen2002.github.io/Agent-bench-website/)** — Evaluates physical, strategic, and spatial reasoning across 410 task environments, including the EP-100 subset. Date: 2026-10-19 (arXiv v1; [source](https://arxiv.org/abs/2610.27039)).
- **[Kinex](https://stacx-lab.github.io/kinex/)** — Connects coding agents to robot devices, tools, and reusable skills, including ROS 2 integrations. Date: 2026-10-15 (v1.0.0 release; not a first-publication claim; [source](https://github.com/stacx-lab/kinex/releases/tag/v1.0.0)).
- **[RoboSimStudio](https://robosimstudio.github.io/)** — Provides an interactive Newton-based toolkit for humans and coding agents to refine robot-task simulations from observed behavior. Date: 2026-10-13 (arXiv v1; [source](https://arxiv.org/abs/2610.18835)).
- **[SpatialHarness](https://emilia113.github.io/SpatialHarness/)** — Gives a frozen multimodal robot policy complementary virtual views from a synchronized simulated scene for fine manipulation. Date: 2026-10-08 (arXiv v1; [source](https://arxiv.org/abs/2610.12457)).
- **[RoboQuest](https://declare-lab.github.io/RoboQuest/)** — Tests whether physical agents search, inspect, and interactively test before committing to actions in ten mobile-manipulation tasks. Date: 2026-10-07 (arXiv v1; [source](https://arxiv.org/abs/2610.10388)).
- **[BiGym 2.0](https://bigym2.github.io/)** — Compares learned policies and coding-agent-developed controllers on simulated Unitree G1 household tasks. Date: 2026-10-06 (arXiv v1; [source](https://arxiv.org/abs/2610.07594)).
- **[Video2World](https://aetherlabsai.github.io/Video2World/)** — Evaluates coding agents that turn embodied videos into executable interactive simulations and refine them through execution feedback. Date: 2026-10-03 (arXiv v1; [source](https://arxiv.org/abs/2610.04432)).
- **[DexAgent](https://dexagent1.github.io/)** — Transforms a human video and task prompt into robot-training trajectories using adaptive tools, verifiers, and a self-evolving library. Date: 2026-09-28 (arXiv v1; [source](https://arxiv.org/abs/2609.35318)).

## Verification limits

Project-page descriptions and paper metadata were checked against author-maintained sources. Linked code is the destination advertised by each project page; this check does not establish code completeness, reproducibility, license suitability, or independent replication of reported results. No benchmark scores are compared across incompatible evaluation settings.
